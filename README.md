# Formula 1 Race Performance Analysis
A Python-based analysis of Carlos Sainz's victory at the 2023 Singapore Grand Prix

## Project Overview
This project uses real Formula 1 race data to analyse Carlos Sainz's race performance and strategy during the 2023 Singapore Grand Prix.
The analysis focuses on:
- Lap pace throughout the race
- Medium and Hard tyre stints
- Tyre age and lap-time behaviour
- Safety Car and Virtual Safety Car periods
- Pit-stop timing
- Late-race pace compared with Lando Norris, George Russell and Lewis Hamilton
- The late-race gap between Carlos Sainz and Lando Norris
## Data Source
Race timing, lap, stint, pit-stop, race-control and interval data were retrieved using the OpenF1 API.
